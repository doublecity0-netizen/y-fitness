# Y · 角色养成

一个适合手机浏览的静态个人记录页面：同一对角色按上海时间，每周七天自动轮换穿搭与姿势。首页保留三个属性入口，点开后记录体重、学习和锻炼；另有当日训练计划。

## 本地运行

无需安装前端依赖，无需构建。电脑安装 Python 3 后，在本目录运行：

```sh
python3 -m http.server 8000
```

再打开 http://localhost:8000 。关闭终端中的服务即可结束预览。也可用其他静态文件服务器。

## 文件

- `index.html`：页面、样式与交互代码。
- `assets/y-pose-mon.png` 至 `assets/y-pose-sun.png`：七张当前角色插画。
- `.gitignore`：排除环境变量、日志、导出记录和本地杂项。

七套主题依次为：废土日常、轻机能、运动日、城市夜色、黑白机车、粉白幻想、长风出行。按 `Asia/Shanghai` 的星期自动切换，每周重复，不会每天调用外部生成服务。

## 数据与隐私

所有个人记录仅保存在当前浏览器、当前网址来源的 `localStorage` 中，没有后台、账户或跨设备同步。本仓库不包含已保存的个人记录。

更换域名、浏览器或设备，不会自动带入原网址下的记录；清理浏览器数据也可能移除记录。请勿把实际记录导出文件、密码、令牌、环境变量文件或原始个人照片提交到仓库。

三项属性按真实记录计算。学习和锻炼按不同日期累计，不按周清零，也不因休息扣分。体重使用首次真实记录与最新记录追踪目标变化，不生成虚假起点。这里不是身体成分检测或医疗评估。

训练计划只展示代码中已经配置的日期，不会自动生成或重复未来的训练安排；请按自己的情况确认。
